📚 Kütüphane Otomasyon Sistemi

Bu proje, SQL Server ve C# kullanılarak geliştirilmiş bir kütüphane otomasyon sistemidir. Temel amacı, kitap takibi, üye yönetimi ve ödünç alma-verme işlemlerini kullanıcı dostu bir arayüzle kolaylaştırmaktır.

🛠 Teknolojiler

C# (Windows Forms)

Microsoft SQL Server

T-SQL (prosedürler, triggerlar)

Crystal Reports (raporlama)

🔍 Temel Özellikler

🔐 Giriş Sistemi

Admin ve personel rollerine göre giriş ve yetki kontrolü

👤 Yönetim İşlemleri

Admin ve personel bilgilerini ekleme, güncelleme, silme

Kimlik, e-posta ve telefon gibi alanlarda doğrulama kuralları

📘 Kitap Yönetimi

Kitap ekleme, düzenleme, silme

Kitap listesini Excel'e dışa aktarma ve Excel'den içeri alma

👥 Üye İşlemleri

Üye kayıt, güncelleme ve silme

Silinen üyeler otomatik olarak yedek tabloya kaydedilir

🔄 Ödünç ve İade

Kitap ödünç verme ve iade işlemleri

Geciken iadeler için otomatik ceza hesaplama

💾 Veritabanı Yedekleme

Mevcut veritabanını yedekleme ve geri yükleme seçenekleri

📄 Raporlama

Crystal Reports ile dinamik arama sonuçlarının PDF çıktısını alma

🚀 Kurulum

SQL Server'da veritabanını oluşturun.

Gerekli tabloları ve prosedürleri çalıştırın.

Visual Studio'da projeyi açın.

App.config dosyasındaki bağlantı cümlesini kendi SQL sunucunuza göre düzenleyin.

Uygulamayı başlatın.


📄 Lisans

Kodlar ve yapılar tamamen açık kaynaklıdır. Kişisel ve eğitsel amaçlarla kullanılabilir.
